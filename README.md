# Tiny Chess 4K — golf51

A chess engine in 4,092 bytes of Python, built for the make.fun **tiny-chess-01** bounty: PeSTO tapered evaluation, PVS search with a fixed node budget, and a rung-scoped harvested opening book (Philidor, Semi-Slav, Queen's Indian).

Local practice on the kit trials (8 games each): Elo 1,990 / 1,990 / 1,845 — mean 1,942, 20W/4D/0L.

The engine is `main.py` alone (Python 3.13, standard library only, deterministic fixed-node search). MIT licensed — see `LICENSE`.
